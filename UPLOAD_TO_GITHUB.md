# Cara Upload Project Ini ke GitHub

1. Buka https://github.com/new dan log masuk ke akaun GitHub.
2. Isi **Repository name**: `ESP32-Flame-Detection-Water-Pump`.
3. Isi **Description**: `ESP32-based flame detection prototype that controls a water pump through a relay.`
4. Pilih **Public** (kalau nak jadikan portfolio) atau **Private**.
5. Tekan **Create repository**. Untuk elakkan konflik, tak perlu tick tambah README atau .gitignore semasa cipta repo.
6. Extract fail ZIP project yang disediakan.
7. Dalam repo GitHub yang baru, tekan **uploading an existing file** atau **Add file > Upload files**.
8. Upload `Project_flame_1.ino`, `README.md`, `.gitignore` (dan `UPLOAD_TO_GITHUB.md` kalau mahu panduan disimpan dalam repo). Fail `.gitignore` mungkin tersembunyi pada sesetengah komputer kerana nama bermula dengan titik; pastikan ia dipilih.
9. Isi commit message `Initial commit: ESP32 flame detection project` dan tekan **Commit changes**.

**Nota:** Jangan upload fail ZIP sahaja sebagai kandungan repo. Extract dahulu dan upload fail di dalamnya.
